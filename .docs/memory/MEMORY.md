## 記録方法（記録するときだけ読む）

- 再利用可能な学びだけを記録する。既存文書から分かる事実、その場限りのログ、秘密情報・個人情報は書かない。
- 振り分け: 固有名詞を除いても適用条件を含めて意味が通るものは `.docs/knowledge/KNOWLEDGE.md`（汎用）、それ以外や迷うものはここ（固有）。汎用知見を追記したら報告に1行添える。集約先へのコピーはユーザーが行う。
- 固有知見のカテゴリ: `pitfalls.md`（失敗回避）、`environment.md`（環境）、`decisions.md`（判断理由）、`preferences.md`（作業上の好み）。書式は各ファイルに従う。
- 索引は `- [カテゴリ] 日付 — 要約` の1行。最大20項目を目安に統合し、有効な知見を件数だけのために捨てない。古い記述は根拠を確認して更新する。
- `.docs/update.md` は変更内容、メモリは次回の判断改善を扱う。
