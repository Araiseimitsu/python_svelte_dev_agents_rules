# 変更履歴

新しい記録を先頭に書く。追記時は先頭付近だけ読む。詳細な過去の経緯は `git log` を参照する。

## 2026-10-02 スキル配置ディレクトリの .agents/skills/ への移行

- Claude Code および Antigravity など複数エージェントでの共通利用に対応するため、スキル配置先をルート直下の `skills/` から `.agents/skills/` に移動した。
- `AGENTS.md` の参照先（§0）およびプロジェクト構成（§4）に `.agents/skills/` を反映した。

## 2026-09-28 軽量作業用テンプレートの追加と superpowers の無効化

- `templates/lite/` を追加した。単発スクリプト・小さなツールや試作・データ分析や調査・文書や設定作業向けで、技術は固定せず着手時に確認して数行の計画を了承後に進める。コピーして使う独立構成。
- lite は本格版を参照しないため、`AGENTS.md` §11（承認範囲と安全確認）を変更したときは `templates/lite/AGENTS.md` §7 も確認する。
- superpowers プラグインを本格版・lite とも `.claude/settings.json` の `enabledPlugins` で無効化した。起動時に「スキルを必ず使う」指示を注入し、計画書・段階承認・サブエージェント活用を促すため、本ルール（計画書不要、委譲は明示依頼時のみ、文書は `.docs/`）と衝突する。主要な機能は `AGENTS.md` と `.docs/workflow.md` で代替済み。

## 2026-09-28 常時読み込み量の削減とトークン効率ルールの新設

- `AGENTS.md` を圧縮した。安全確認（§11）は項目を維持したまま表現を簡潔にし、一般論・重複・メタ記述を削減。参照先を §0 の表に集約した。
- 節を再編した（旧§5・§6・§10 → §5 技術スタック、旧§7・§8 → §6 設計、旧§15 → §8、旧§17 の記録方法 → `.docs/memory/MEMORY.md`、旧§18・§19 → §13、旧§20 は削除）。`.docs/` の節参照を更新した。
- §3「トークン効率」を新設した: 範囲を絞った読み取り、再読の抑制、依存・生成物を読まない、検証出力の絞り込み、`update.md` の先頭のみ参照。
- `.claude/settings.json` を追加し、依存・生成物・キャッシュのディレクトリの Read を deny した。lock ファイルは競合解消で読む必要があるため除外していない。
- `.docs/workflow.md` の重複節（並行処理・確認が必要な場合）を統合し、§1〜§6 に再採番した。
- 本ファイルの 2026-09-07 より前の履歴を、現行ルールの由来だけを残す要約に圧縮した。

## 2026-09-07 承認範囲と通常作業の整理

- 新規の既定と既存プロジェクトの尊重を分離した。
- 通常編集・承認済み依存変更の lock 更新・自己修正を通常作業とし、破壊的操作や実環境変更の承認範囲を明確化した。
- 入力検証は Backend を正本、Frontend は操作支援とした。局所的な型・定数・状態の同居を許可した。
- 外部ツールの文書から特定アプリの実装前提を除いた。メモリ索引を件数だけで削除しない方針にした。

## 2026-07-02〜08-25 現行ルールの由来（要約）

- `AGENTS.md` を全エージェント共通の正本とし、技術別の詳細・例・手順を `.docs/` に分離した。
- 既定はシングルエージェント。マルチエージェント・反復レビューは運用の結果、遅く精度も下がったため、ユーザーの明示依頼時のみとした。
- 一般論を削り、プロジェクト固有の決定と安全確認に絞る方針を定めた。機械検査できる規則は lint / CI へ移し、検査設定を正本とする。
- 空のパススルー層を禁止し、小規模では層の統合を許可した。
- 学びを `.docs/memory/`（固有）と `.docs/knowledge/`（汎用）に分けた。迷う場合は固有に倒す（汎用側への混入を防ぐため）。
