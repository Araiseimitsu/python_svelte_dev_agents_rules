# KNOWLEDGE.md — 汎用知見

**他プロジェクトでも通用する学び** だけを記録する。
このリポジトリ固有の学びは `.docs/memory/` に書く（振り分け基準は `AGENTS.md` §17）。

本ファイルはユーザーが定期的に見直し、必要なものを集約リポジトリへ手動でコピーする。
エージェントは集約先へ書き込まない。ここに正しく貯めるところまでが役割である。

## 書き方

- 1メモ = 1セクション。新しいものを上に追記する。
- プロジェクト固有の前提を持ち込まない。適用条件を明示し、ツール名や言語名は必要に応じて記載してよい。
- 秘密情報・個人情報は書かない。
- 同種のメモは統合する。追記だけで肥大化させない。

```markdown
## YYYY-MM-DD タイトル（何についての知見か）

- **分類**: ツール / 言語 / 環境 / 設計 / プロセス
- **知見**: どこでも通用する形で書いた事実
- **根拠**: なぜそう言えるか（踏んだ失敗・確認した挙動）
- **適用場面**: どんなときに効くか
```
