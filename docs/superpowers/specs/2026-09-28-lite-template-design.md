# 軽量作業用テンプレート（lite）設計

## 目的

本格開発用テンプレート（リポジトリ直下の `AGENTS.md` / `.docs/`）とは別に、軽量な作業向けの AI エージェント用ルールテンプレートを用意する。
常時読み込み量を最小に保ちつつ、安全確認の水準は本格版と同等にする。

## 対象作業

- 単発スクリプト・自動化
- 小さなツール・試作
- データ分析・調査
- 文書・設定作業

使う技術は作業ごとに異なるため、技術を固定せず着手時にユーザーへ確認する。

## 方針（決定事項）

- 配置: 本リポジトリの `templates/lite/`。利用時はフォルダごとコピーする。
- 独立構成（案A）: lite 内で完結させ、本格版のファイルを参照しない。安全確認は本格版 §11 の要約を持つ。
- 二重管理対策: 本格版 `.docs/update.md` に「安全ルールの変更時は lite 側も確認する」旨を記録する。
- 本格版から持ち込まないもの: 層設計、テストファースト必須、memory の4分類、反復レビュー、README。

## ファイル構成

```txt
templates/lite/
├─ AGENTS.md                  # 常時読み込み（目安 40〜60 行）
├─ .claude/settings.json      # 読み取り除外（言語非依存）
└─ .docs/
   ├─ python.md               # Python (uv) の既定。Python 使用時のみ読む
   ├─ knowledge.md            # 汎用的な学び（記録時のみ読む）
   └─ update.md               # 重要な変更の記録（新しい順）
```

## AGENTS.md の構成

| 節 | 内容 |
| --- | --- |
| 0. 位置づけ | 軽量作業用。継続保守・複数人利用・DB や認証を扱う規模になったら本格版への移行を提案する |
| 1. 着手時の確認 | 目的・技術・成果物の形・検証方法のうち、既存ファイルから分からないものだけ確認する。3〜5行の計画を示し、了承後に作業する。自明な小修正は確認を省略する |
| 2. 応答 | 日本語。結果・検証・残る制約を簡潔に報告する |
| 3. トークン効率 | 絞って読む、読み直さない、出力を絞る |
| 4. 実装 | 既存の構成・技術を尊重する。依頼外の整理・依存追加をしない。エラーを握りつぶさない |
| 5. 検証 | 変換・判定ロジックは簡易テストか実行結果で確認する。ファイル更新は元データを壊さない方法（別名出力・バックアップ）を既定とする。未検証の項目は明示する |
| 6. 秘密情報 | `.env` を Git 管理しない、実値を表示しない、外部送信しない |
| 7. 承認が必要な操作 | 削除・破棄・初期化、`.env` 実値や OS 設定の変更、push・公開・外部送信、依頼範囲外の依存追加。承認済み範囲では確認を繰り返さない |
| 8. 委譲 | サブエージェント・外部 AI はユーザーの明示依頼時のみ |
| 9. 記録 | 重要な変更は `.docs/update.md`、汎用的な学びは `.docs/knowledge.md`。該当時のみ |
| 10. 参照先 | Python 使用時は `.docs/python.md` |

## 補助ファイル

- `.claude/settings.json`: `node_modules`, `.venv`, `venv`, `dist`, `build`, `__pycache__`, `.pytest_cache`, `.mypy_cache`, `.ruff_cache`, `coverage`, `htmlcov`, `.ipynb_checkpoints`, `target` の Read を deny。
- `.docs/python.md`（10〜15行）: `uv` を使う。プロジェクトは `pyproject.toml` / `uv.lock`、単一ファイルは PEP 723 インライン依存 + `uv run` を許容。`pip` 単独使用をしない。
- `.docs/knowledge.md`: 記録方法（汎用的で再利用可能な学びのみ、秘密情報を書かない、1行形式）と空の索引。
- `.docs/update.md`: 記録方法（新しい記録を先頭に）と初回記録。

## 検証

文書のみの変更のため、以下で確認する。

- AGENTS.md が目安行数内で、上表の全節を含む。
- 本格版 §11 の承認対象を要約で欠落させていない。
- lite 内の参照パスがすべて実在する。
- `settings.json` が有効な JSON である。
